Sparrow

Browser Extension Dashboard Design Web Design

While studying Human-AI interaction patterns, I observed how users repeatedly retry prompts due to the absence of meaningful feedback from AI systems. Sparrow was designed to optimise AI workflows by helping users improve prompt clarity, structure, and context in real time.

Problem Overview

Iceberg Model — mapping the hidden layers of the AI prompting problem

Problem Statement

In the absence of a feedback response, professionals are unaware about the effectiveness of their prompt. This results in multiple retry behaviour leading to time wastage and frustration.

Why It Matters

Being embedded into workplace workflows, Ineffective AI prompting is not just a usability issue but a growing cost and productivity concern for organisations.

The Solution

Sparrow browser extension — real-time prompt feedback alongside AI tools

Interact with Prototype ↗

Key Features

01

Real-time prompt feedback system

The extension analyses prompts as users interact with AI tools, providing contextual feedback on clarity, structure, and completeness to help users write more effective prompts.

02

Prompt performance tracking dashboard

A companion dashboard visualises prompting patterns over time, enabling users to identify recurring mistakes, track improvement, and build stronger AI interaction habits.
